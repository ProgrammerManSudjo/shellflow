Put the wallpapers you want to bundle in this folder (png, jpg, jpeg, webp, bmp).
The installer offers to copy them to %USERPROFILE%\Pictures\Wallpapers, the folder the starter config's wallpapers widget uses.

Size: GitHub rejects files over 100 MB and the repo should stay under about 1 GB. A few dozen wallpapers are fine in git.
For a big collection, leave this folder empty, zip the images as wallpapers.zip, attach that file to a GitHub Release,
and set $WallpapersUrl in install.ps1 (the README says how).
